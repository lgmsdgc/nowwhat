# Seed data

`missions.ts`가 검수된 미션 60개를 모읍니다.
기존 16개 ID를 유지하고 `soloMissions`, `friendMissions`, `coupleMissions`,
`familyMissions`에 각각 11개를 추가했습니다.

각 미션은 설명·체크리스트·수행 조건·시간·1인당 비용·이동 범위·안전 플래그를 포함합니다.
`missionFactory.ts`는 공통 기본값과 Zod 검증을 담당합니다.
음식은 성분·위생·가격을 확인하며, 요리는 칼·불·뜨거운 물 없이 가능한 재료만 사용합니다.
외출은 익숙한 공개 보행로·왕복 상한·이용 가능 여부 확인을 포함하고 야간 후보에서 제외합니다.

12개 카테고리와 동행별 후보 15개 이상, 집 20개 이상·무료 25개 이상을 테스트합니다.
0원·15분·집·에너지 1·야간 조건에도 모든 동행과 강도에 안전한 후보가 있습니다.
`tests/unit/missions.test.ts`가 입력 조합 커버리지와 안전 메타데이터를 검증합니다.

실제 장소·영업시간·가격을 조회한 목록은 아닙니다. 장소를 사용하는 미션은 첫 단계에서
이용 조건을 확인하며, STEP 5에서 DB seed로 옮겼습니다.
`achievements.ts`는 STEP 7의 검수된 칭호 9개입니다. 로컬 판정과 SQL 시드가 같은 규칙을 사용합니다.
새 템플릿 보상은 난이도별 100~180 EXP이며 명시적인 `baseExp`로 개별 검수 보상을 지정할 수 있습니다.
기존 세션 스냅샷의 보상은 변경하지 않습니다.
홈의 MissionPreview는 소개용 예시이며 추천 템플릿 목록으로 사용하지 않습니다.
